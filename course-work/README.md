# Практические задания Linux Learn

## Запуск

Из корня workspace:

```bash
./course-work/run-lessons.sh
```

Runner выполняет практические упражнения уроков 3–29 и сохраняет учебные файлы
в `course-work/lessons/lessonNN/`. Упражнение урока 14 использует уникальную
временную папку `lesson14-run.*`, чтобы повторные запуски не перезаписывали
предыдущий каталог `storage`.

Письменные ответы к урокам 1–2 и пояснения к ограничениям среды находятся в
[answers.md](answers.md).

## Содержимое

- Уроки 3–12: навигация, `ls`, справка, системные текстовые файлы, HTTP/curl,
  API-запросы, сеть, пакет `htop`.
- Уроки 13–22: создание и изменение файлов, удаление, перенаправление,
  конвейеры, `grep`, `find`, обработка текста, права и архивы.
- Уроки 23–29: процессы, переменные окружения, Bash-сценарии, циклы, обработка
  файлов, REST API и анализ каталога DummyJSON.
- Урок 30: [github-report](../github-report/README.txt), самостоятельный
  запускаемый проект, который получает открытые задачи `cli/cli`, формирует
  отчёт и архив.

## Проверенные результаты

Проверены выходные JSON и текстовые файлы, permissions, архивы, списки
процессов, shell-сценарии, повторное выполнение runner’а и работа итогового
сценария при недоступном API. Из-за поведения GitHub API первые 30 записей
включают pull request; итоговый отчёт хранит полный ответ, но считает в списках
задач и меток только настоящие issues.

`htop` уже был установлен в исходном Codespace. Пакет проверен и запущен в
batch-режиме, но не удалён, чтобы не менять предустановленную системную среду.
Для процессов урока 23 применялся `kill` по конкретным PID вместо широкого
`killall`.
